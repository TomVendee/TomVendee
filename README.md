## ✦ Projets publics

### [lendrr-suivi](https://github.com/TomVendee/lendrr-suivi)
`Rust` `Axum` `sqlx` `React` `PostgreSQL` `MCP`

Chef de projet d'une équipe de 6 sur un casier connecté, j'ai construit l'outil de pilotage qui a remplacé Asana. Il gère les dépendances avec décalage automatique, le plan de charge, un Gantt avec chemin critique, les alertes et la synthèse hebdo, et expose un serveur MCP pour piloter le planning depuis un assistant IA. En production.

### [cassiopee-canary](https://github.com/TomVendee/cassiopee-canary)
`Go` `Kubernetes` `PostgreSQL` `MariaDB` `MongoDB`

Application témoin qui vérifie, voyant par voyant, que chaque option de la plateforme de déploiement Cassiopée prend réellement effet dans le cluster : variables, sondes, limites, TLS, WebSocket, bases de données, CronJob.
